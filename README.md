# 🍳 Recetario Web Interactivo — Next.js App

Aplicación web para buscar y explorar recetas de cocina de algunos postres en tiempo real utilizando la API de TheMealDB.

🔗 **Demo en vivo:** [Ver en Netlify](https://recetariowe.netlify.app/)

---

## 🛠️ Stack Tecnológico

* **Core:** Next.js 16 (App Router), React, TypeScript
* **Estilos & Iconos:** Tailwind CSS, Lucide React
* **Datos & Despliegue:** TheMealDB API, Netlify

---

## ✨ Funcionalidades

* **Búsqueda dinámica:** Encuentra platillos por nombre, categoría o ingrediente.
* **Vista detallada:** Consulta ingredientes, medidas e instrucciones paso a paso.
* **Interfaz responsiva:** Adaptada a móviles y escritorio.

---

## 🚀 Inicio rápido

1. **Clona e instala:**
   ```bash
   git clone https://github.com
   cd tu-repo-recetario
   npm install
   ```

2. **Ejecuta en desarrollo:**
   ```bash
   npm run dev
   ```
   Accede a [http://localhost:3000](http://localhost:3000) en tu navegador.
